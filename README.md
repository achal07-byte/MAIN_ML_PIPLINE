# AI AutoML Pipeline Generator

An intelligent pipeline generator that leverages Large Language Models to automate Machine Learning workflows.

## Features
- Interactive Chat UI for pipeline configuration
- Smart File Upload (CSV, Images)
- Automated EDA and Preprocessing
- AutoML Model Selection
- Exportable Python Code

## Tech Stack
- **Frontend**: React + Vite + TailwindCSS
- **Backend**: FastAPI + Python
- **AI**: Anthropic API

## Getting Started
### Using Docker
```bash
docker-compose up
```
